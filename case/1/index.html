三人 Bot 团队三天把一个产品想法做成上线应用 Quiet Desk

照着 PM/Design/QA 三 Bot 分工和现成角色 prompt，一个人也能把想法推到上线，只需回 yes/no 做审批。
任务背景
作者 Adam Faik 的 Markdown 笔记散落在多个 GitHub 仓库里、很难连起来读，他想做一个把仓库文件像书一样阅读、还能自动推荐相关文件和关系图谱的应用，但不想自己全程写代码盯进度。
做法步骤 (7 步)
  1. 1. 从 x.ai/bot 下载 Grok Bot，用 Cursor 账号登录，确认套餐包含 Grok Bot（Premium 或旧版付费 Cursor 套餐）
  2. 2. 在 Cursor 仪表盘 Cloud Agents 里把默认模型设为 Grok 4.7 并关掉 Fast（默认开着、按两倍 token 计费）
  3. 3. 新建 PM Bot，只跟它对话：发角色说明让它负责到底、写 brief、调度其他 Bot，合并/部署/发布前必须先问作者，并在设置里加 Ask first 规则兜底
  4. 4. 再建 Design Bot（先定设计方向、每版评审截图）和 QA Bot（只测试不改代码，像新用户一样用并尝试弄坏它）
  5. 5. 把产品想法发给 PM Bot，它逐个提问澄清后写出 brief 并转给 Design Bot 定风格
  6. 6. 需要写代码时 PM Bot 启动 Cursor 云端编程 agent 干活，QA Bot 逐版测试回报问题
  7. 7. 作者三天里给 PM Bot 发了 42 条消息，一半只是 yes/OK/done，第三天晚上应用上线
关键提示词 (Prompt)
PROMPT TEMPLATE
From now on, you are my PM Bot. Remember this role.
产出与证据
应用 Quiet Desk 已上线公开运行：可把 GitHub 仓库的 Markdown 按书页方式阅读，在示例仓库上识别出 248 对原文并无链接的相关文件对并画成关系图；Bots 借 Cursor agent 写的全部代码已公开在 GitHub 仓库 The-AI-Thinker/quiet-desk（原文给出仓库名与上线截图为证）。从发想法到首个构建启动只用了 20 分钟，作者本人只投入了几小时碎片时间。
复现要点
需要含 Grok Bot 的套餐（文中 Premium 为每月 30 美元，旧付费 Cursor 套餐也可）；全程用量装进了一个 Premium 套餐的每周额度，托管免费。角色 prompt 作者在文中完整公开了 PM/Design/QA 三份，可直接改自己的产品名套用。
踩坑提示
原文提醒：只写在 Bot 记忆里的规则只是引导，真正能拦住合并/部署的是 Auto-review 里的 Ask first 设置；第一个构建耗时超过两小时，别指望每步都快；每个 Bot 的每次回复（含 Bot 之间互发）都计用量，所以让 Design/QA 只在被 @ 时回复。
