从 189 个仓库里挑出 20 件 Grok Bot 开源装备：联网、邮件、桥接、保活与中文配方一次配齐

不用自己翻 GitHub：这份清单把能直接给 Grok Bot 加能力的社区项目按痛点分好了类，先挑一件装上、派个有明确终点的活跑通再说。
任务背景
作者雨哥向前冲长期实测 Grok Bot 等 AI 工具。他说组团队、派活那类内容大家已经刷得很多，真正缺的是给 Grok Bot 本体加装备的工具选型：他自称在 GitHub 上搜到 189 个 Grok Bot 相关仓库，这次只挑能直接给它加能力的 20 个，按用途分好类发了出来，并配了两张图（一张全清单、一张按痛点选装备的对照图）。
做法步骤 (5 步)
  1. 1. 先按痛点定位分类：让它会得更多（01-06）、长任务和省额度（07-10）、中文抄作业（11-15）、桌面硬件（16-17）、没有 Grok Bot 也能玩的替代品（18-20）
  2. 2. 只挑一件先装：想让它自己上网查资料选 web-access；工作邮件在 QQ、163、腾讯企业邮选 cn-mail-mcp；写代码时不想切出去派活选作者自研的 grokbot-bridge-mcp；长任务总被云电脑休眠冻住先配 bot-keepalive + Wake on Done；额度总不够先看 grokbot-local-agent 与 grokbot-usage-cli
  3. 3. 打开对应的 GitHub 仓库，先看 README 和它要的权限再决定装不装（原帖收录的 20 个仓库链接都在原帖正文里）
  4. 4. 按仓库说明接入自己的 Grok Bot；涉及邮箱的 cn-mail-mcp 默认只读、用授权码不用密码
  5. 5. 装好后先派一个有明确终点的小任务验收，跑通了再考虑加第二件
产出与证据
这份清单本身就是产出：20 个项目逐个写明用途，分 5 类呈现——联网补强 web-access、一键剪藏 grok-bot-clipper、国内邮箱 MCP、Cursor/Codex/Claude Code 里一句话派活的 bridge、终端管理 CLI、Telegram 桥；保活与额度组有 bot-keepalive、Wake on Done、本地 Pi 跑重活省额度的 grokbot-local-agent、查本周额度的 usage-cli；中文组有配方库 awesome-grokbot-playbooks 与《Grok Bot 橙皮书》等；硬件组是两款 ESP32/M5Stack 桌面设备。原帖截至读取时 47,205 次观看、6 次书签，配图 2 给出了痛点到编号的对照选法。文中 189 个仓库、配方库 197 条目、橙皮书 1.6 万字等数字均为作者原帖说法。
复现要点
需要 Grok Bot 账号；部分桥接与保活项目另需自己的 Cursor、Codex 或 Claude Code 环境，本地跑重活的项目需自备模型账号。中文用户门槛最低的入手顺序是先看中文抄作业组（11-15）的配方库与橙皮书，再按痛点装一件工具。
踩坑提示
原帖明确提醒：这 20 个都是社区项目、不是官方出的，装之前先看清它要哪些权限。另注意：第 04 条 grokbot-bridge-mcp 是作者自己写的，有自荐成分；《Grok Bot 橙皮书》是今年 8 月写的，作者自己说部分细节以官方为准；18-20 是没有 Grok Bot 时的开源替代，不是 Grok Bot 本体的扩展，选时别混淆；作者的结论也是装备多不等于干得多，先跑通一件再说。清单里各仓库的具体数字（条目数、字数、翻车记录数）为原帖说法，本库未逐仓复核。
