Peter Yang：@bot 把数千条剧评变口味档案

看到好帖不用收藏吃灰：@bot 一句变成可复用的研究任务。
任务背景
Peter Yang 想验证 Grok Bot 的 X 接入与 @bot 交接：常在 X 看到值得深挖的帖子却收藏后不再看，也想复盘自己账号表现与竞品舆情。
做法步骤 (5 步)
  1. 1. 在 Grok Bot 接好 X 插件，确认 @bot 转发给自己绑定的 Bot，而非像 @grok 公开回帖
  2. 2. 在电视剧讨论帖下 @bot，让它分析数千条回复
  3. 3. 后续留在 Bot 私聊，让 Bot 把结论写进 Markdown 口味档案
  4. 4. 同法做 Dots 对 Grok Bot 的按日情绪、声量、主题与原文链接看板
  5. 5. 再让 Bot 按月、形式、主题复盘自己账号，提炼可验证的内容假设。
产出与证据
产出：更新过的 Markdown 口味档案、Dots 对 Grok Bot 舆情看板、自己账号分月复盘。原文记录边界：Bot 读不了加密私信，排期回复与日历邀请仍需本人批准。
复现要点
需 Grok Bot 订阅并连接 X；@bot 触发私人 Bot 任务，付费用户有免费 X API 额度起步，额度以套餐为准。
踩坑提示
Bot 读不了加密私信；舆情看板是方向性参考，搜索词与抽样会带偏图表，要对照原文链接复核。
