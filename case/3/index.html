让 Grok Bot 读代码库批量生图：两小时生成 74 张游戏卡牌素材并接回游戏

把占位图清理这种逐张手活整包交给 Bot：它自己读代码搞清每张图是什么、逐张写 prompt 生图、裁成透明 PNG 再接回工程。
任务背景
独立游戏开发者 Danny Limanseta 在做一款第一人称 roguelike 卡组构筑游戏，工程里堆满占位图，以前靠他一张一张手动生成替换。他拿到 Grok Bot 早期内测约一周，想先拿这件最烦的活开刀。
做法步骤 (5 步)
  1. 1. 把自己已有的美术生成工具网页指给 Grok Bot，让它通过该页面干活（而不是换一个新模型）
  2. 2. 让 Bot 读游戏代码库，自己弄清每个占位图对应的用途
  3. 3. Bot 为每个素材逐个撰写定制生图 prompt 并生成图片
  4. 4. Bot 把成品裁剪、清理成透明背景 PNG
  5. 5. Bot 把 74 张素材全部接回游戏工程，作者在游戏里统一验收
产出与证据
原文（作者 X 原帖，经 Agents In Use 逐项核对原帖后整理）称：约两小时产出 74 张清理裁剪完毕的卡牌素材并全部接入游戏，替代了原来逐张手动的流程，作者之后所有美术素材活都走 Grok Bot；同帖还提到它建了加速试玩的技能、GitHub 推送自动上传 itch.io 的流水线、经 Figma MCP 从 PRD 出 UX 流程与线框图。原帖在 X 上约 992 个点赞、37.5 万浏览（grokbot.dev 用例页数据）。

复现要点
需要 Grok Bot 账号和一个可网页访问的自有生图工具/页面；原帖没有公开逐字 prompt，复现时按步骤把工具地址和代码库给 Bot、让它先列占位图清单再批量执行；本条来源页的 suggested prompt 是整理方自拟、非作者原文，故关键提问留空。
踩坑提示
原文附带提及的边界：Bot 顺手做的退订营销邮件清理漏掉了几封，批量自动活仍要抽查；试玩加速技能的速度作者还在继续调。
