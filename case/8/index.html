给 Grok Bot 建一个 Learning Scout：按水平和每周 4 小时自动拼学习计划

把选课这种反复查页面的活做成专职 Bot：给它学员画像和时间预算，它逐页核对级别与时长后交一份不超时的学习计划，还能存成每周例行。
任务背景
DataCamp 教程团队实测 Grok Bot 的技能/例行/审批机制，选了一个真实学习场景落地：学员会 Python、懂基本 LLM 概念、刚接触 agent 编排，每周只有 4 小时，而目标轨道总时长 6 小时装不下，需要有人替他挑、排序并卡总时长。
做法步骤 (6 步)
  1. 1. 从 Grok Bot 入口页下载桌面端，用 Cursor 账号登录（Grok Bot 无永久免费档，付费走合资格 Cursor 套餐或 SuperGrok）
  2. 2. New 新建 Bot 命名 Scout，在 Edit Profile 写长期规则：只做 DataCamp 学习内容策展并匹配水平与时间预算；把画像当背景而不是任务、等单独消息再开工；每个候选必须打开它自己的课程页才能推荐；级别和时长照页面原文引用、页面没写就写 not listed；保留来源链接、绝不编课程信息
  3. 3. 把易变的学员信息写进云电脑上的 /workspace/learner-profile.md 作为每周运行的事实源（目标、预算、背景、偏好、已学完清单）
  4. 4. 发本周任务（原文见关键提问）：要求打开每个候选页核对、总时长不超过 4 小时、从基础到实操排序、每项给标题/类型/级别/时长/链接/适配理由/顺序，最后给总时长和本周目标，做完即停、不许擅自报名
  5. 5. 在 Agent Computer 里盯它真的逐页打开核对而不是抄搜索摘要，逐行验收链接、级别、先修和总时长
  6. 6. 验收通过后把流程存成技能并挂每周例行，下周只更新画像文件即可重跑
关键提示词 (Prompt)
PROMPT TEMPLATE
Build me a weekly DataCamp learning plan. The learner is comfortable with Python, understands basic LLM concepts, is new to AI agent orchestration, and has 4 hours available this week.
产出与证据
实测产出：Scout 返回了一份通过逐页核对的学习计划，含每项资源的标题、类型、页面原文级别与时长、链接、适配理由和学习顺序，总时长卡在 4 小时内并给出本周目标；过程中它打开了 Introduction to AI Agents 页面（页面标 Basic、1 小时 30 分），时长对上了但级别抄错，被作者在验收环节抓出并纠正（原文截图与过程记录为证）。
复现要点
需要 Grok Bot 付费访问（Cursor Pro/Pro+/Ultra、Teams 或 SuperGrok 等，文中称最新公告后 SuperGrok 与 Cursor Pro 均含）；注意 Grok Bot 要求云端数据存储，Cursor 账号开着 Legacy Privacy Mode 会启动不了；研究环节只查公开页面、不需要 DataCamp 登录。
踩坑提示
原文实测踩坑：第一次建 Scout 时它把画像描述当成任务直接开跑、跑出一份无关的 ETL 计划，要重建并补两条等待规则（目标含糊先提问、不许擅自建号/报名/购买）；摘要会过期或漏级别时长，只能用它找候选、结论必须以课程页为准；页面被挡、要登录或出 CAPTCHA 时应让 Bot 停下来叫人接管，且不要把密码粘进聊天；删掉 Bot 不等于清掉共享电脑上的文件和登录态。
