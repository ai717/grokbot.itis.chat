六 Bot 团队接管网店两天实测：老板 Bot 拍板、页面 Bot 定时发品、广告 Bot 清旧广告

看看一个人怎么用六个分工 Bot 跑网店的选品、货源、发品和广告，以及它真实卡住的地方——没有销售数据就直说没有。
任务背景
作者运营一个网店，想验证 Grok Bot 是不是玩具：设一次、Bot 自己持续干，而不是每次都要他下命令。他另有一个 Axagen 副业也要 Bot 帮忙管邮箱和社区。
做法步骤 (4 步)
  1. 1. 装 Grok Bot 桌面端开免费试用（需绑卡验证），按一岗一 Bot 建：名字、头像、标签（营销/行政/研究）和职责描述，描述也可以直接在聊天里说给 Bot、它自己填
  2. 2. 让 Bot 互相认识：在聊天里告诉它另一个 Bot 是谁、是它的伙伴，两个老板 Bot 置顶方便找
  3. 3. 组网店团队：Mano Master 老板 Bot 看网站拍板产品上不上架；Facebook 页面 Bot 设定例行，工作日 10:00 和 16:00 检查网站新品并自动发帖、删差评；Facebook 广告 Bot 走 Facebook API 接管广告（已让它删掉旧广告，完成得很干净）；选品研究 Bot 去 Facebook 广告库和竞品网站找在卖的产品；AliExpress 货源 Bot 按研究 Bot 给的思路找同类货源（只看对方发来的截图）；Fixer Bot 修网站问题
  4. 4. 第二个老板 Bot 在 Plugins 里连 Gmail 和 Google Calendar（点 Authorize 浏览器确认即可），让它读邮件、分析 YouTube 频道、读 Skool 社区给活跃建议
产出与证据
两天实测结果表（原文逐项）：本地电脑任务（给录视频的软件做配置）几分钟完成；广告 Bot 删除旧广告完成；页面 Bot 例行已按工作日 10:00/16:00 运行；选品到货源的交接在视频里直播跑通但没当场上架新品；用量表刚重置显示 7%→8%。作者明说销售、流量、广告效果都没测到，不编数字。
复现要点
需要 Grok Bot（免费试用要绑卡）；广告 Bot 建议走 Facebook API 而不是点 Ads Manager 界面；没内置插件的应用可经 Zapier 连接；本文由作者视频整理成文，DEV 页面内嵌完整实测视频可对照。
踩坑提示
原文踩坑：Bot 会被 CAPTCHA 卡住，要自己解完点 I'm done 它才继续；Skool 登录超时需手动重登；搭建期频繁弹审批比较费时；速度比人慢，优势是关机后云端继续跑；各 Bot 登录态实际共享，在一台上登了 Facebook 其他 Bot 也能用，权限别想当然。
